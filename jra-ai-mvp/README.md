# JRA AI MVP

目的は、AIを自分で扱えないユーザーでも「自分専属の競馬AI」を使っている感覚を得られる、スマホ優先の無料MVPを作ること。

## 現在のMVP
- 今日のレース一覧カード
- AI評価スコア
- BUY / CAUTION / PASS
- A/B/C/PASS区分
- 軸耐久性・荒れ度・推奨点数
- Simple / Expert 切替
- 全馬評価と短い理由
- AIが警戒する負け方
- フォーメーション表示
- IPAT順の除外表示サンプル

## 固定する運用思想
- 人気・オッズは能力評価に入れない
- 予想封印後にのみ市場情報を利用
- T-4分でEV判定
- 基本10点、条件により7〜8点、最大12点
- 12点を超えないと主要シナリオを覆えない場合はPASS候補
- 買い目は必ずフォーメーションを先に生成し、全組合せを内部展開確認してから不要組合せをIPAT順で除外表示する

## 次の実装
1. JRA実データ接続
2. 予想エンジン接続
3. 予想封印データ保存
4. T-4分EV判定
5. 結果取得とPDCA
6. Candidate Coverage / Ticket Coverage集計

初期MVPではログイン、課金、SNS、チャットは入れない。
